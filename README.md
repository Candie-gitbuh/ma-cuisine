# Ma Cuisine V4 — PWA

Cette version est conçue pour être installée comme une application depuis Chrome sur Android.

## Installation sur téléphone
1. Les fichiers doivent être hébergés sur une adresse HTTPS.
2. Ouvrir l'adresse dans Chrome.
3. Menu ⋮ > "Installer l'application" ou "Ajouter à l'écran d'accueil".
4. L'icône Ma Cuisine apparaît ensuite comme une application.

## Important
Le service worker et l'installation PWA nécessitent HTTPS (sauf localhost).
GitHub Pages est une option gratuite pour héberger ces fichiers.
